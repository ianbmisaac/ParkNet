Luces (LEDs de plazas)
Automático = verde cuando la plaza está LIBRE; se apaga cuando llega el auto (y aquí suena la alarma del admin).
Pantalla personalizada
Modo DATOS = "LIBRES: x/2" + rotación P1/P2/Barrera. Con el texto propio el admin escribe cualquier mensaje (bienvenida, hora de cierre, promociones…).
La plaza 2 la controla la web (virtual). La plaza 3 quedará lista para el tercer espacio futuro (el firmware actual la ignora).
🎭 Simulación por plaza (sobreescribe sensores)
sensores reales
En modo simulación cada clic alterna ocupar/liberar en esa plaza y envía la orden al Arduino por MQTT. Desactiva para volver a mostrar lo que reportan los sensores reales.
🔧 Tests (panel anterior)
Test de cableado: muestra el valor crudo de los sensores y mueve el servo 0°→90°→180°→0°. Sirve para comprobar que cada cosa está en el pin que crees. "Volver a los sensores" deja la plaza 2 LIBRE; "Sincronizar" reenvía el estado completo de la placa.
Registro en vivo de la placa (logs)
Sensor IR, barrera, pantalla, comandos aceptados y rechazos de seguridad — lo que pasa en el Arduino llega aquí al momento.
Seguridad: esta página exige el documento admins/{uid} en Firestore (rol entregado solo desde la consola — nadie puede auto-asignarse). El MQTT de administración firma cada orden con el token del grupo; sin token el Arduino rechaza el comando.
